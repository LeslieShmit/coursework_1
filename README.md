# Bank Operations Analyzer

## Описание проекта

**Bank Operations Analyzer** — приложение для анализа банковских транзакций, хранящихся в Excel-файле.

Проект обрабатывает данные по операциям и формирует несколько аналитических отчетов в формате JSON:

* главная аналитическая сводка по операциям;
* поиск операций, содержащих номер телефона в описании;
* отчет по операциям выбранной категории за последние 3 месяца.

Дополнительно приложение получает актуальные курсы валют и котировки акций через внешние API и включает их в итоговый отчет.

---

## Основные возможности

### Главная страница (`main_page`)

Формирует JSON-ответ, содержащий:

* приветствие в зависимости от времени суток;
* информацию по банковским картам:

  * последние 4 цифры номера карты;
  * общую сумму расходов за месяц;
  * рассчитанный кешбэк;
* топ-5 крупнейших транзакций;
* актуальные курсы валют;
* актуальные котировки акций.

### Поиск операций по номеру телефона

Позволяет найти все операции, в описании которых присутствует номер телефона.

### Отчет по категории

Формирует отчет по операциям указанной категории за последние 3 месяца относительно выбранной даты.

Пример категорий:

* Супермаркеты
* Транспорт
* Рестораны
* Аптеки
* Развлечения

## Установка

### Клонирование репозитория

```bash
git clone https://github.com/LeslieShmit/Bank_operations_analyzer.git
cd Bank_operations_analyzer
```

### Установка зависимостей

```bash
poetry install
```

### Активация виртуального окружения

```bash
poetry shell
```

---

## Настройка проекта

### Переменные окружения

Создайте файл `.env` на основе шаблона:

```bash
cp .env.example .env
```

Заполните необходимые API-ключи и параметры подключения.

### Пользовательские настройки

Файл:

```text
user_settings.json
```

содержит список валют и акций, используемых при формировании аналитического отчета.

Пример:

```json
{
  "user_currencies": [
    "USD",
    "EUR"
  ],
  "user_stocks": [
    "AAPL",
    "MSFT",
    "GOOGL"
  ]
}
```
